About The Project

Project Overview

AI Phishing URL Detector is a machine learning-based cybersecurity application designed to identify malicious and phishing URLs before users interact with them. The system analyzes URLs using a trained machine learning model and provides security insights to help users avoid online threats.

Key Features

  • AI-Based URL Classification
  • Real-Time Phishing Detection
  • Confidence Score Analysis
  • Security Recommendations
  • Analytics Dashboard
  • Scan History Tracking
  • CSV Report Export

Technology Stack

  • Python
  • Flask
  • Machine Learning
  • TF-IDF Vectorization
  • SQLite Database
  • HTML, CSS & JavaScript

Future Scope

  • Browser Extension Integration
  • Email Phishing Detection
  • Deep Learning Models
  • Real-Time Threat Intelligence
  • Cloud-Based Deployment
